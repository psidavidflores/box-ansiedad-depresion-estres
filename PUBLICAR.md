# Publicación del Box Ansiedad, Depresión y Estrés

Esta carpeta contiene una versión preparada para un repositorio independiente de GitHub Pages.

## Qué incluye

- `docs/`: catálogo web completo; GitHub Pages debe publicar desde `main` y `/docs`.
- `docs/recursos/`: archivos digitales organizados por temática.
- `docs/previews/`: vistas previas de la primera página de los PDF.
- `docs/assets/brand-logo.jpg`: identidad visual de la marca.
- `artes/`: piezas de promoción del Box.

## Revisión antes de hacer público

La selección automática excluyó archivos temporales, bases de datos del sistema y un ejecutable. Antes de publicar, se debe confirmar que cada libro, manual, test, hoja de corrección y material cuenta con autorización de distribución o está en dominio público. GitHub no sustituye esa revisión de derechos de autor.
